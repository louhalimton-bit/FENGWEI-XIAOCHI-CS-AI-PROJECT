### 1.4 Project Scope and Learning Goals

#### Target learners
Beginners studying Software and Symbolic AI. Learners are assumed to be able to use a computer and follow step-by-step instructions, but have no previous experience with AI, programming, or formal logic.

#### Learning goals
After completing the materials, learners will be able to:
1. Explain what software is, how it processes information (input, processing, output), and describe symbolic AI as an explicit knowledge representation approach.
2. Describe how an ordinary program makes decisions using step-by-step instructions and $\text{IF-ELSE}$ conditions.
3. Identify facts and conditions in a simple, familiar situation.
4. Represent a situation using facts and $\text{IF-THEN}$ rules, including $\text{AND}$ conditions.
5. Describe the roles of the knowledge base and inference engine in a rule-based system.
6. Follow a worked example of forward chaining and apply the steps to trace a new example.
7. Give examples of software and symbolic AI applications (e.g., expert systems) and explain how rule-based components integrate into ordinary software.
8. Compare rule-based reasoning with fixed program logic (strengths and limitations).
9. Classify system vs. application software, state two OS functions, and describe programming language evolution.
10. Describe algorithm features/representations, differentiate iteration vs. recursion, and trace searching and sorting.
11. Describe main data structures and trace stacks, queues, binary search trees, and breadth-first search.
12. Describe software process models, modularity, quality assurance, and write simple SQL queries.
13. Construct truth tables, apply *modus ponens* and *modus tollens*, and write statements in predicate logic.
14. Represent knowledge via logic, semantic networks, frames, and rules.
15. Follow a backward-chaining example from a goal to facts and explain MYCIN's operation.
16. Represent state space problems, trace uninformed/informed search, calculate minimax values, and explain local search.
17. Parse sentences using small grammars and describe symbolic NLP applications.
18. Compare rule-based and machine-learning assistants and explain why hybrid systems are useful.

#### Mini lecture plan
* **Topic:** Rule-based reasoning (Chapter 9 focal point: How a rule-based system uses facts and $\text{IF-THEN}$ rules to reach a conclusion).
* **Core Scenario (Library Loan):**
  * *Facts:*
    1. Member has a valid library card.
    2. Member has no overdue books.
    3. Requested book is available.
  * *Rules:*
    * $\text{R1: IF } \text{valid card} \land \text{no overdue books} \implies \text{may borrow}$
    * $\text{R2: IF } \text{may borrow} \land \text{book available} \implies \text{loan approved}$
  * *Forward Chaining Execution:* Apply $\text{R1}$ to infer "may borrow", then apply $\text{R2}$ to infer "loan approved".
