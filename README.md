## Project Purpose
### This repository holds the shared learning content for the team project

**"How Can Software Use Rules to Reach a Conclusion? An Introduction to
Symbolic AI and Forward Chaining"**, our selected module in
**Software and Symbolic AI**.

The purpose of the project is to turn a technical topic into clear,
beginner-friendly learning materials. Everything is first written as
Markdown in this repository, which is the single source of truth. The
Study Guide and Test Bank, PPT Slides, Video Tutorials and Live Mini
Lecture are all built from it, so the information stays consistent.

By the end of the module, learners will be able to:
- Explain what software is and how it processes information
  (input, processing, output), and describe symbolic AI as an approach
  that represents knowledge explicitly;
- Describe how an ordinary program makes decisions with IF–ELSE
  conditions, and trace a short program;
- Represent a simple situation using facts and IF–THEN rules, including
  an AND condition;
- Describe the roles of the knowledge base and the inference engine in a
  rule-based system;
- Follow a worked example of forward chaining, then apply the same steps
  to a new example;
- Give an example of software and of symbolic AI (such as an expert
  system), and explain how the two can be combined;
- Explain one strength and one limitation of rule-based reasoning
  compared with fixed program logic.

## Intended Learners

The materials are written for **beginners** studying Software and
Symbolic AI, or AI in general.

**Assumed:** learners can use a computer and follow step-by-step
instructions.

**Not assumed:** no previous experience with AI, programming or formal
logic. Key terms are defined before they are used in activities or worked
examples. One familiar scenario, a library loan decision, is used
throughout so learners can follow a single example from facts to
conclusion.
